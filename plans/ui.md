This PoC currently implemented will form the base for a strategic hard sci-fi game where players
have multiple outposts, mining sites, freighter routes along low dv lagrange manifolds, fleets of
military fusion-drive ships with 50-500 km/s dv but low acceleration, lots of logistics work etc.

The graphics layer is very important to convey as much information visually as possible, but a decent
amount of info and control input will need to be in the UI. For example, fleet transport management
may look like: Select fleet on graphics layer -> world space anchored ui showing dv, days of supplies,
 % of missiles remaining as visual bars and icons -> select 1 or more destinations using click and
shift-click -> UI pops up allowing you to specify a dv budget and optimize for arrival time or dv and
then several matching routes (transfers + waiting periods).

Other interactions would be
colony management: setting construction, resource and production allocations, etc.
trade / freight route set up and management: assigning ships, grouping into convoys, logic for types
of goods to bring and when, expected fuel costs, tof and profit (if civilian)
Ship class customization: choosing what reactor(s), max reaction mass, missile tubes, types and
quantities, point defense types, locations and quantities, railguns, crew modules, sensor modules,
etc.
